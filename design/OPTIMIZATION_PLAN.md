# Optimisation and simulation plan — rev B (Fusion model)

Planned 2026-11-26. Applies to `design/cad_fusion_revB/` (part data in `scripts/pod.py`, `wing.py`, `tail.py`,
`linkage.py`, `jigs.py`; build kit in `build-kit/`, generated by `tools/build_kit/`). The FreeCAD models stay the
reference. Every number used in a decision comes from the part data, a measured value, or a cited source.

## Goals (from the user)

1. **One balsa stock.** Buy a single balsa type (one thickness, one grade). Every balsa part is made from it: thicker
   parts by laminating (sandwiching) layers, strips laser-cut from the same sheet. The BOM gets simpler.
2. **Lightening cut-outs.** Remove balsa where it carries little load, with the strength checked.
3. **Other design optimisations.** Mass, part count, sheet count, build time, CG, robustness.
4. **Engineering simulations for the competition abstract.** Aerodynamics (Flow5, the successor to XFLR5), CFD and
   FEA (SolidWorks Simulation / Flow Simulation, or Ansys if better), with figures and tables the abstract can use.
5. **Real data only.** Material properties, and any number not computed here, come from a cited source (for example
   the USDA FPL *Wood Handbook* for balsa, manufacturer datasheets for carbon and plywood). No invented values.

## Where we start (from `build-kit/MATERIALS.md`, `design/cad_fusion_revB/mass_table.md`)

- Laser stock: balsa light 1.5 / 3 mm; balsa medium 1 / 1.5 / 2 / 3 mm; lite-ply 1.5 / 3 mm; birch ply 1 / 1.5 / 3 mm
  (41 sheets, 1.59 m²).
- Strip stock: 3×5, 6×6 triangle, 3×6, 3×3, shaped LE 6×16.3, hard 3×6 spar caps, TE wedges 5.2×25, aileron LE
  3×15, 1.5 mm sheet for D-box / centre sheeting / cap strips; carbon 0.5×3.
- Mass: pod 165 g (rev B FreeCAD 133 g: no hex lightening yet), wing 157 g, tail 78 g, empty ≈ 721 g,
  score ≈ 138 (score = 996 × 100 / empty mass).
- Tools on this PC: Fusion (bridge `tools/fusion_bridge/`), SolidWorks 2026 + Flow Simulation, Ansys 2024 R1
  (Fluent, Mechanical / MAPDL) with MCP servers, MATLAB R2024b with MCP. Flow5 / XFLR5 are **not installed**.

## Phases (one at a time; each phase is its own session; the orchestrator waits for each)

### P1 — Single-stock study (no CAD changes)
- Table of every balsa part: today's stock, thickness, grade, load it carries.
- Compare candidate single stocks: **1.5 mm medium** (the likely answer: thin parts stay 1 layer, 3 mm parts become
  2 cross-grain layers, 6 mm strips become 4 laminated layers), 2 mm, 3 mm. For each: lamination schedule per part,
  mass change, number of 100×1000 sheets to buy, glue mass, build effort, strength (MATLAB hand calcs, extending
  `design/cad_fuselage_balsa/strength_estimate.m`).
- Strip stock from the same sheet: capstrip, keels, ledges, longerons (L of two strips instead of a triangle), spar
  caps (laminated with carbon), LE (laminated block or a D-box wrapped round a small LE), TE (two 1.5 skins over a
  spacer instead of a wedge), aileron LE, cap strips.
- Ply: say whether lite-ply / birch ply can be replaced by cross-laminated balsa (formers, tray, saddles), and keep
  ply only where a hand calc says it is needed (firewall, bulkhead, front stop, grip zone?).
- **Output:** `design/optimisation/P1_single_stock.md` with a recommendation. **Gate:** the user picks the stock.

### P2 — Lightening and design-optimisation study (no CAD changes)
- Cut-out candidates with mass saved and stress margin: hex lightening of the pod sides (rev B saved ≈ 7 g),
  windows in formers, floor and deck under film, rib truss / bigger holes, saddles, tail frames, tray, hatch.
- Other optimisations: merge or drop parts, fewer sheets (better nesting), CG at X 80 check, hatch magnet seats,
  joint simplification, anything else the data shows.
- Stress checks: MATLAB hand calcs; FEA (Ansys MAPDL) on the critical parts (front stop under the 10 g nose-in water
  load, the side grip zone, the bulkhead / boom joint, the wing spar at the design load factor).
- **Output:** `design/optimisation/P2_lightening.md`: a ranked list (grams saved, margin, risk). **Gate:** the user
  approves the list.

### P3 — Implement in the Fusion model
- Change the part data (`pod.py`, `wing.py`, `tail.py`, `linkage.py`, `jigs.py`) for the chosen stock and cut-outs;
  rebuild in Fusion through the bridge (only one Fusion job at a time); run `check_model.py` (interference),
  `check_joints.py`, `mass_summary.py`, `laser_loops.py` + `laser.py`; regenerate the build kit, BOM, PDF and game
  data with `tools/build_kit/`; update READMEs.
- **Output:** a branch with the new model, DXF, STL, BOM, mass table. **Gate:** the user approves before `main`.

### P4 — Simulation tool evaluation
- SolidWorks: connect the SolidWorks MCP, check what it can drive (the MCP has CAD tools; check whether Flow
  Simulation / SolidWorks Simulation can be run through it or through the SolidWorks API), import the STEP, try one
  small CFD and one small FEA case.
- Ansys: Fluent (CFD) and MAPDL (FEA) through their MCP servers on the same small cases.
- Flow5: check the licence / download (the user installs it if wanted; downloads need the user's OK); if Flow5 is not
  available, compare XFLR5 / AVL.
- **Output:** `design/simulation/P4_tool_choice.md`: what each tool can do here, speed, credibility for an abstract,
  recommendation.

### P5 — Aerodynamics
- Flow5 (or the chosen tool): wing + tail + fuselage panel / VLM model from the real geometry: lift curve,
  polars, Cm-α, neutral point, static margin with CG at X 80, trim at empty and 1 L loaded, stall speed vs the
  existing estimates in `design/aero/`.
- CFD (Fluent or SolidWorks Flow Simulation): the wing at cruise and near the stall, or the full aircraft;
  pressure / velocity pictures for the abstract; compare with Flow5.
- **Output:** `design/simulation/aero/` (inputs, results, figures) and a summary.

### P6 — Structure
- FEA of the wing spar / D-box under the design load (n × loaded weight, safety factor 1.5), the pod front stop and
  floor under the water load, the boom / bulkhead joint, the tail under a gust or landing load. Material data from
  cited sources.
- **Output:** `design/simulation/structure/` and a summary with margins.

### P7 — Abstract package
- Figures (renders, Flow5 plots, CFD pictures, FEA contour plots), tables (mass, score, margins, aero numbers), a
  references list (every source used), and a 1–2 page abstract draft in plain English.
- **Output:** `design/abstract/`.

## Rules for every session
- One phase per session; the orchestrator starts the next only after reading the last report.
- Use Opus at high effort for design and engineering; a cheaper model is fine for mechanical checks.
- Fusion, SolidWorks and Ansys are single-instance here: never two sessions driving the same program.
- Commit on the session's own branch; **ask the user before pushing to `main`**.
- Do not touch the user's uncommitted `design/cad_fuselage_balsa/Fuselage_revB_balsa.FCStd`.
- Write numbers with their source; say when a value is an estimate.
